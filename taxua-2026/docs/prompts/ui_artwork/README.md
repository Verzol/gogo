[Documentation index](../../README.md) · [Existing scenery prompts](../illustrated_scenery/README.md)

Copy one complete prompt block per generation. Each includes its canvas, subject, composition, painting style and export instructions. Attach the linked reference images for a closer match to the existing artwork.

Reuse the existing backpack, headlamp, bus, coffee, tree, lake and ridge illustrations. Photo previews use existing photographs; the trail index can use existing landmarks. No new artwork is needed for either.

For terrain, generate each composition in day, bluehour and night palettes using the matching [day](../../../figures/scenery/painted/ridge_near.png), [bluehour](../../../figures/scenery/painted/ridge_near_bluehour.png) or [night](../../../figures/scenery/painted/ridge_near_night.png) reference. Approve one silhouette first, then recolor that output for the other two palettes without changing its shape or transparency.

Save originals under `figures/raw/ui_artwork/`. Request the highest supported native resolution at the listed ratio; do not upscale. Supplied originals, measured crops and their runtime integration are documented in [Illustrated journal controls](../../ui-artwork.md).
